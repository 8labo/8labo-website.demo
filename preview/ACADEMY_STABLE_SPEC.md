# ACADEMY stable visual spec

Baseline locked on 2026-08-28.

- Desktop section outer spacing: approximately 40px top / 40px bottom.
- Mobile section outer spacing: approximately 18px top / 18px bottom.
- Internal heading spacing must stay smaller than section outer spacing.
- CLASS & LEVEL background: light blue (#dfeef7).
- CURRENT CLASSES background: near-white (#f8fafc), full viewport width from its heading through the class cards.
- Hero / needs / change / program / activity / reason / voice / supervision / FAQ retain alternating section colors.
- Existing card shapes, typography, content, and layout should not be redesigned by spacing/color maintenance changes.
- Photo slots: show CMS photo when present; otherwise show Coming Soon. CMS photos use cover so no letterbox bands remain.
- VOICE is CMS-driven; empty state is Coming Soon.
- INSTRUCTOR placeholder is transformed at runtime to PROGRAM SUPERVISION and links to the representative profile.

When changing ACADEMY later, preserve this file as the reference baseline and modify only the requested area unless a deliberate redesign is approved.
